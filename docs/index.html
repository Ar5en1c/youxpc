Give your AI agentits own cursor.Yours never moves.

YouxPC lets Claude Code, Codex or any MCP agent work your Mac apps. It reads each window as a short numbered list and presses the controls itself, while you keep working. Open source, and it runs on your Mac.

$ curl -fsSL https://raw.githubusercontent.com/Ar5en1c/youxpc/main/install.sh | bash
Watch a real run Other ways to install macOS 14 or later

the agent's yours, exactly where you left it

Under every window there is a list.

Your screen is pixels. Underneath, macOS keeps a description of every button and field. YouxPC hands that to the agent with an id on each control, and presses by id.

    What it will not touch.
    
      
    Accessibility access is all or nothing at the operating-system level, so the narrowing happens in YouxPC. Pick an app and see what an agent gets back.
    
    
    
    
    
      
      
        
    • Blocked appsPassword managers, Keychain Access, System Settings, permission prompts, terminals and the app hosting the agent are refused by default. You can switch to a strict allowlist.
      • 
        
    • A never-press list you setGive it words such as Send, Delete or Pay and any control named with one is refused. It is off until you set it, it guards against accidents, and it is not a security boundary.
      • 
        
    • Terminal only by approvalAn agent can start only the commands you list, with no shell prompt, and its keys go to that program alone.
      • 
        
    • Nothing leaves your MacNo telemetry. Screen text goes only to the agent you connected.
      •

    Running in a minute.
    
      
    Three steps, no account, no key. It is an ordinary MCP server that runs on your Mac.
    
    
    
    
    
      
    step 1
    Install
    A short script that downloads the release, checks it and puts youxpc in ~/.local/bin. Read it first if you like.
    
        
    curl -fsSL https://raw.githubusercontent.com/Ar5en1c/youxpc/main/install.sh | bash
    
      
    step 2
    Tell your agent
    It speaks plain MCP over stdio. For Claude Code:
    
        
    claude mcp add youxpc -- ~/.local/bin/youxpc mcp
    
      
    step 3
    Allow it once
    macOS asks for Accessibility permission for the app your agent runs in. That app is what you are trusting, so choose it deliberately.
    
        
    ~/.local/bin/youxpc doctor
    
    
    
    
    Prefer to build it? git clone https://github.com/Ar5en1c/youxpc.git && cd youxpc && swift build -c release (needs Xcode 26; this is also the way on an Intel Mac).
    
    
    
      
    Where it stops. macOS only, and terminal sessions use Apple's Terminal.
    
      
    Canvas apps, games and custom-drawn interfaces have nothing to list, so they still need the real pointer for a moment.
    
      
    Shortcuts with Command or Option bring the app to the front.
    
      
    There is no confirmation step before sending, deleting or paying. The never-press list is the only guard, and you have to set it.
    
      
    VS Code exposes almost nothing to accessibility, so it is close to unusable here.
    
      
    Tested on Chrome, Brave, Calculator, TextEdit and Terminal. Other apps will have rough edges; please report them.
